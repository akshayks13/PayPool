# Domain modules

Each directory below is a bounded capability with its own routes, application
services, domain models, repositories, and tests when implementation begins.
The initial folders deliberately contain no code. Detailed ownership is in
[`docs/repository-structure.md`](../../../docs/repository-structure.md).

- `identity`, `retailers`, `sellers`, `catalog`, `geo`
- `procurement`, `negotiation`, `pools`, `optimization`
- `acp`, `payments`, `fulfillment`, `receipts`
