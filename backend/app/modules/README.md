# Domain modules

These directories reflect the original ownership plan. The running procurement,
identity and fulfillment domain is in `app/platform`; `negotiation` contains the
typed agent/extraction foundation. Other folders remain planning namespaces.
Detailed historical ownership is in
[`docs/repository-structure.md`](../../../docs/repository-structure.md).

- `identity`, `retailers`, `sellers`, `catalog`, `geo`
- `procurement`, `negotiation`, `pools`, `optimization`
- `acp`, `payments`, `fulfillment`, `receipts`
